# NeuroTA — Researcher Mode

Браузерный режим исследователя: один график и слои структуры рынка.

- Directional Change, Rolling Window, PIP
- Уровни Market Profile
- Трендовый канал
- Гармоники, Head & Shoulders, флаги
- Загрузка CSV (date, open, high, low, close, volume) и демо-ряд

Алгоритмы считаются в браузере по идеям neurotrader888/TechnicalAnalysisAutomation.
Торговли и MT5 в этой версии нет.
